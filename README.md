# ⚙️ System Flow (Behind the Magic)

1. 📝 Admin registers RFID → assigns user + vehicle type  
2. 🚗 Vehicle arrives → RFID scanned  
3. ☁️ ESP32 checks Firebase → balance + price  
4. 🎯 Decision:
   - ✅ Success → Deduct + Open gate + Send SMS  
   - ❌ Fail → Show error + Keep gate closed  
5. 📊 Everything logged in dashboard
